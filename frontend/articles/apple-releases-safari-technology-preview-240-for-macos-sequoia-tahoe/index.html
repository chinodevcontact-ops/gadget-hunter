Apple、実験的ブラウザ「Safari Technology Preview 240」をリリース ― macOS Sequoia/Tahoeに対応

Apple Releases Safari Technology Preview 240 for macOS Sequoia/Tahoe

📋 Summary

  • 実験的ブラウザ「Safari Technology Preview」のバージョン240が公開
  • CSS、HTML、Web API、WebAssemblyなど広範な領域で修正と改善を実施
  • macOS SequoiaおよびmacOS Tahoeに対応し、フィードバック収集を目的とする
  • Safari Technology Preview 240, an experimental browser, has been released
  • Updates include fixes and improvements across CSS, HTML, Web API, and WebAssembly
  • Compatible with macOS Sequoia and macOS Tahoe, aimed at gathering user feedback

Appleは本日、将来のSafariブラウザ向け機能を先行テストする実験的ブラウザ「Safari Technology Preview」の最新版、バージョン240をリリースしました。2016年3月に初めて導入されたこのプレビュー版は、開発者や一般ユーザーからのフィードバックを募ることを主な目的としています。

今回のアップデート、バージョン240では、CSS、Editing、Forms、HTML、Media、PDF、Rendering、SVG、Scrolling、Web API、Web Extensions、Web Inspector、WebAssemblyなど、多岐にわたるコンポーネントにおいてバグ修正とパフォーマンス改善が施されています。

対応OSは、最新のmacOSであるmacOS SequoiaおよびmacOS Tahoeです。既存のSafariブラウザと並行して動作可能で、開発者アカウントなしでダウンロード・利用が可能です。

Apple today released Safari Technology Preview 240, the latest update to its experimental browser designed to test features planned for future Safari versions. First introduced in March 2016, the preview aims to gather feedback from both developers and general users.

Version 240 brings bug fixes and performance improvements across a wide range of components, including CSS, Editing, Forms, HTML, Media, PDF, Rendering, SVG, Scrolling, Web API, Web Extensions, Web Inspector, and WebAssembly.

The update is compatible with the latest macOS versions, macOS Sequoia and macOS Tahoe. Safari Technology Preview can run side-by-side with the standard Safari browser and does not require a developer account for download or use.
