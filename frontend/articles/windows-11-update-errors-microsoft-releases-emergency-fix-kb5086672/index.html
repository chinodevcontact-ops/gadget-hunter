Windows 11のアップデートエラー、Microsoftが緊急修正パッチKB5086672をリリース

Windows 11 Update Errors: Microsoft Releases Emergency Fix KB5086672

リーク信頼度 Leak Credibility 65%

📋 要約

📋 Summary

  • Microsoftは、広範囲なインストールエラーにより取り下げたWindows 11のKB5079391アップデートに対し、緊急の帯域外修正KB5086672を公開した。
  • KB5086672は、以前のKB5079473、KB5085516、そして取り下げられたKB5079391を統合したパッケージである。
  • 本アップデートにより、エラーコード「0x80073712」を含む既存のインストール問題が解決され、今後のQoL改善の第一歩とされている。
  • Microsoft has released an emergency out-of-band fix, KB5086672, for the previously pulled Windows 11 KB5079391 update due to widespread installation errors.
  • KB5086672 integrates prior updates KB5079473, KB5085516, and the withdrawn KB5079391 into a single package.
  • The update resolves existing installation issues, including error code '0x80073712', marking a first step towards future quality-of-life improvements.

Microsoftは先日、広範囲なインストールエラーを受けて一時的に提供を停止していたWindows 11の非セキュリティ機能アップデート「KB5079391」に対し、緊急の対策を講じたと発表しました。

本日、同社は問題の原因を特定した上で、この不具合に対処するための帯域外（out-of-band）アップデート「KB5086672」をリリースし、安全に適用可能になったと報告しています。この最新のKB5086672は、3月10日のKB5079473、3月21日のKB5085516、そして3月26日に取り下げられたKB5079391を全て統合したパッケージです。これにより、以前発生していた「一部の更新ファイルが見つからないか、問題があります」といったインストールエラー（エラーコード: 0x80073712）が完全に解消されたとしています。

本アップデートは、Windows 11のKB5079473以降のアップデートを既にインストールしているデバイス向けにWindows Updateを通じて提供されるほか、Microsoft Update Catalogからの手動ダウンロードも可能です。現時点では、このアップデートに関する既知の問題は報告されておらず、Microsoftは今後、サポートドキュメントを通じて情報を提供する方針です。KB5086672は、Windows 11のアップデートでユーザーが経験してきた問題の解決に向けたMicrosoftの初期的な取り組みの一つであり、同社が約束するOSオーバーホール（全面的な見直し）の始まりとなることが期待されます。

Microsoft has announced an emergency measure to address widespread installation errors that led to the temporary withdrawal of Windows 11's non-security feature update, KB5079391.

Today, the company released the out-of-band update KB5086672, stating that the root cause of the issue has been identified and the update can now be safely applied. This latest KB5086672 package integrates the KB5079473 (March 10), KB5085516 (March 21), and the previously pulled KB5079391 (March 26) updates. This combination aims to definitively resolve the previous installation error message, 'Some update files are missing or have problems. Error code: (0x80073712).'

The update is available via Windows Update for Windows 11 devices that have already installed KB5079473 or a later update, and can also be downloaded manually from the Microsoft Update Catalog. Currently, no known issues have been reported with this update. Microsoft has indicated that KB5086672 is one of the first steps towards resolving the update issues experienced by Windows 11 users, hopefully marking the beginning of a promised overhaul of the OS.
