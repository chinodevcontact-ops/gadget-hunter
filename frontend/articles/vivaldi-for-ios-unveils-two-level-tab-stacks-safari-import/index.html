Vivaldi、iOS版に待望の二段階タブスタックとSafariインポート機能を導入

Vivaldi for iOS Unveils Two-Level Tab Stacks & Safari Import

リーク信頼度 Leak Credibility 65%

📋 要約

📋 Summary

  • VivaldiブラウザのiOS版バージョン7.9がリリース
  • ユーザーから要望の多かった二段階タブスタック機能をiPhoneおよびiPadに搭載
  • Safariからのブックマーク、パスワード、履歴、支払い情報のインポート機能を追加
  • Vivaldi browser version 7.9 released for iOS
  • Introduces highly requested two-level tab stacks for iPhone and iPad
  • Adds import functionality for bookmarks, passwords, history, and payment info from Safari

Vivaldiは、iOS版ブラウザの最新バージョン7.9をリリースし、iPhoneおよびiPadユーザー向けに「二段階タブスタック」機能を導入したことを発表しました。この機能は2021年からAndroid版で提供されており、iOSユーザーからの最も要望の多かった機能の一つとされています。

二段階タブスタックは、関連するタブをグループ化し、選択されたスタック内のタブのみが第二の行に表示されることで、インターフェースの整理を可能にします。また、Vivaldi 7.9では、Safariからブックマーク、パスワード、閲覧履歴、保存済み支払い情報を直接インポートする新機能も追加されました。さらに、スタートページに日替わりの厳選写真を表示する「Daily Image」機能も導入され、iPhoneの壁紙と同期することも可能です。本バージョンはApp Storeから既にダウンロード可能となっています。

Vivaldi has officially rolled out version 7.9 of its iOS browser, bringing the much-anticipated "two-level tab stacks" feature to iPhone and iPad users. This functionality, available on Android since 2021, has been cited as one of the most requested features for the iOS platform.

The two-level tab stacks allow users to group related tabs, with the contents of an active stack appearing in a secondary row, thus maintaining a clean interface. Version 7.9 also introduces a new option to directly import bookmarks, passwords, browsing history, and stored payment information from Safari. Additionally, a "Daily Image" feature has been added, showcasing a curated photograph on the Start Page each day, with an option to sync it to the iPhone's wallpaper. Vivaldi 7.9 is now available for download via the App Store.
