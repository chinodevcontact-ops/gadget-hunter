Steamのギフト機能改善！DLC贈るのが楽になった？

Steam's Gifting Update: Easier DLC Gifting?

リーク信頼度 Leak Credibility 65%

📋 要約

📋 Summary

  • ゲームバンドルをギフトする際に、相手が既に持っているコンテンツを自動で除外
  • バンドル価格が自動調整され、相手が持っている分だけ安くなる
  • 相手のライブラリが非公開設定だと、除外されないバグが存在（様子見安定）
  • Automatically excludes content the recipient already owns when gifting game bundles.
  • Bundle price adjusts automatically, reflecting the excluded content.
  • Bug: Exclusion doesn't work if the recipient's library is set to private.

Steamでゲームをギフトする機能がちょっと便利になりましたね。ゲームバンドルを贈る時に、相手が既に持っているDLCとかをSteamが自動で除外してくれるらしいんです。

バンドル価格も自動で調整されるので、無駄な出費を避けられます。もし友達がCoD WarzoneのDLCを欲しいって言われたら、バンドルごと贈るよりも、この機能で必要なものだけ贈った方がスマートですよね。個人的には、サプライズでDLCを贈りたい時に便利かなと思います。

ただ、相手のライブラリが非公開設定だと、Steamが持っているコンテンツを認識できないみたいで、除外されないバグがあるらしいです。どうせいつもの人柱案件だろ？様子見安定ですね（笑）。

中の人の本音 (JP)

正直、地味だけど地味に便利ですね。僕みたいなゲーム好きの友達にDLCを贈ることが多いので、これは助かります。ただ、相手のライブラリが非公開だと認識されないってのは致命的。SteamのAPI制限とかで、どうしても難しいんでしょうか。僕の9070 XTで快適にゲームしたい気持ちもわかるけど、こういう細かい部分も改善してほしいですね。もしこれが本当なら、Steamのギフト機能はもっと使いやすくなるはず。

Steam's gifting feature got a small but useful update. When gifting game bundles, Steam now automatically excludes content the recipient already owns.

The bundle price adjusts accordingly, saving you money. If a friend wants a DLC for CoD Warzone, it's smarter to gift just that DLC using this feature instead of the whole bundle. I think it's especially useful for surprise gifts.

However, there's a bug where Steam can't detect owned content if the recipient's library is set to private. Seems like the usual early adopter issues, so 'wait and see' is the best approach.
