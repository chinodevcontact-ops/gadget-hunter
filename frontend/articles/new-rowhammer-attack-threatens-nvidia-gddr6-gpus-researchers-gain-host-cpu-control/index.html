NVIDIA製GDDR6搭載GPUに新たな「Rowhammer攻撃」の脅威、研究者らがホストCPU制御に成功

New 'Rowhammer Attack' Threatens NVIDIA GDDR6 GPUs, Researchers Gain Host CPU Control

📋 Summary

  • 「Rowhammer攻撃」がGDDR6メモリを搭載するNVIDIA GPUに拡大、ホストCPUへの制御奪取が可能に
  • 「GDDRHammer」と「GeForge」の2チームが、AmpereからAda Lovelace世代のGPUで有効なエクスプロイトを開発
  • 攻撃はGPUのメモリ割り当てを標的とし、ページテーブルを破損させることでCPUの主メモリに対する任意読み書き権限を獲得
  • Rowhammer attacks now extend to NVIDIA GPUs with GDDR6 memory, enabling host CPU control
  • Two teams, 'GDDRHammer' and 'GeForge,' developed exploits for Ampere to Ada Lovelace generation GPUs
  • Attack targets GPU's memory allocator, corrupting page tables to gain arbitrary read/write access to host CPU memory

これまで主にCPUとDDRメモリを標的としてきた「Rowhammer攻撃」が、NVIDIA製GPUのGDDR6メモリにも拡大していることが明らかになりました。複数の独立した研究チームが、この数十年来のメモリ脆弱性を悪用し、現代のグラフィックスハードウェアを危険に晒す方法を発見したと報告されています。

「GDDRHammer」と「GeForge」と名乗る2つの研究グループは、NVIDIAのAmpereからAda Lovelace世代のGPUに搭載されるGDDR6メモリでRowhammer攻撃を成功させ、ホストCPUのメモリを完全に制御するエクスプロイトを開発しました。この攻撃は、GPUのメモリ割り当てを標的とし、制御されたビット反転によってGPUのページテーブルを破損させることで、メインメモリへの任意読み書きアクセス権を獲得します。これにより、攻撃者はデバイス上のメモリ分離をバイパスし、機密データを読み取ったり、悪意のあるコードを実行したりする可能性が生じ、深刻なセキュリティリスクとなります。

A decades-old memory vulnerability known as 'Rowhammer attack,' traditionally focused on CPUs and DDR memory, has now been found to exploit NVIDIA GPUs equipped with GDDR6 memory. Independent research teams have discovered methods to leverage this vulnerability against modern graphics hardware, with implications extending to the host CPU.

Two groups, 'GDDRHammer' and 'GeForge,' have developed functional exploits demonstrating Rowhammer bit-flips on NVIDIA GPUs ranging from the Ampere to Ada Lovelace families. These exploits allow attackers to gain complete control over the host CPU's memory. The critical step involves targeting the GPU's memory allocator and corrupting the GPU's page tables through controlled bit-flips. This grants arbitrary read and write access to the machine's main memory, bypassing memory isolation and posing a significant security risk by potentially allowing sensitive data exfiltration or malicious code execution.
