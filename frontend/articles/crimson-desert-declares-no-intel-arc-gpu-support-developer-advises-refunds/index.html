「Crimson Desert」Intel Arc GPU非対応を表明、開発元は購入者に返金推奨

Crimson Desert Declares No Intel Arc GPU Support, Developer Advises Refunds

📋 Summary

  • Pearl Abyss開発の新作「Crimson Desert」はIntel Arcグラフィックカードをサポートしない方針が判明。
  • 開発元はArc環境での不具合修正を行わず、購入者には返金を検討するよう要請。
  • AMDとNVIDIAはゲームの発売日最適化ドライバを既に提供済みで、AMD独自技術も活用されている。
  • Pearl Abyss announced that its new title, "Crimson Desert," will not support Intel Arc graphics cards.
  • The developer stated it will not fix bugs on Arc systems and advised purchasers to seek refunds.
  • AMD and NVIDIA have already released day-zero optimized drivers, with the game leveraging AMD-exclusive technologies.

Pearl Abyssが開発する新作アクションRPG「Crimson Desert」において、Intel Arcグラフィックカードのサポートが提供されないことが明らかになりました。開発元はFAQにて、Arc GPUでの動作保証や不具合修正を行わないと明言し、Arcユーザーに対してはゲームの返金手続きを検討するよう異例の要請を行っています。

この発表とは対照的に、AMDはAdrenalin 26.3.1 WHQL、NVIDIAはGeForce 595.79 WHQLドライバーを通じて、それぞれ「Crimson Desert」の発売日最適化ドライバを既にリリースしています。さらに、本作ではAMD独自のアップスケーリング技術「FSR 4.1」や、レイトレーシング性能を向上させる「Ray Regeneration」技術が採用されており、AMD製GPU環境での最適化が進められていることが示唆されます。

今回の措置は、Intelがグラフィックカード市場への参入を強化する中で、ソフトウェアサポートの重要性を浮き彫りにする事態と言えるでしょう。

It has been revealed that Pearl Abyss's new action RPG, "Crimson Desert," will not support Intel Arc graphics cards. The developer explicitly stated in an FAQ that it will not guarantee operation or fix bugs on Arc GPUs, making an unusual request for Arc users to consider seeking refunds for the game.

In contrast, AMD has already released day-zero optimized drivers for "Crimson Desert" via Adrenalin 26.3.1 WHQL, and NVIDIA via GeForce 595.79 WHQL. Furthermore, the game utilizes AMD's proprietary upscaling technology "FSR 4.1" and "Ray Regeneration" technology, which enhances ray tracing performance, suggesting optimized performance on AMD GPU environments.

This development highlights the critical importance of software support as Intel intensifies its entry into the discrete graphics card market.
