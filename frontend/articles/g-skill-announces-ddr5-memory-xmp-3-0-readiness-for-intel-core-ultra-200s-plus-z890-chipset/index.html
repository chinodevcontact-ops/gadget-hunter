G.SKILL、Intel Core Ultra 200S Plus＆Z890向けDDR5メモリのXMP 3.0対応を発表

G.SKILL Announces DDR5 Memory XMP 3.0 Readiness for Intel Core Ultra 200S Plus & Z890 Chipset

リーク信頼度 Leak Credibility 85%

📋 要約

📋 Summary

  • G.SKILLの既存および新規DDR5メモリキットがIntel XMP 3.0オーバークロックに対応
  • Intel Core Ultra 200S PlusシリーズプロセッサとIntel Z890チップセットマザーボードをサポート
  • BIOS設定によるプロファイル有効化で、容易かつ確実なメモリオーバークロック性能を実現
  • G.SKILL's existing and new DDR5 memory kits now support Intel XMP 3.0 overclock readiness
  • Confirmed compatibility with Intel Core Ultra 200S Plus Series processors and Z890 chipset motherboards
  • Enables easy and reliable memory overclocking performance via BIOS profile activation

メモリメーカー大手のG.SKILL International Enterprise Co., Ltdは、同社のDDR5メモリキットがIntel Extreme Memory Profile (Intel XMP) 3.0オーバークロックに対応したことを発表しました。

この対応により、Intel Core Ultra 200S Plusシリーズプロセッサおよび互換性のあるIntel Z890チップセットマザーボードにおいて、DDR5 U-DIMMおよびCU-DIMMメモリキットが容易にオーバークロック性能を発揮できるようになります。ユーザーはマザーボードのBIOSでプロファイルを有効にするだけで、メモリ性能を最大限に引き出すことが可能です。

G.SKILLは、この認定を受けて公式のIntel XMP識別ロゴを表示できるようになり、これにより公式にサポートされたDDR5メモリキットとして、エンドユーザーは安心して製品を選択できるようになる見込みです。

G.SKILL International Enterprise Co., Ltd has announced that its existing and new DDR5 memory kits have gained Intel Extreme Memory Profile (Intel XMP) 3.0 overclock readiness.

This support extends to the new Intel Core Ultra 200S Plus Series processors and compatible Intel Z890 chipset motherboards, covering both overclocked specification DDR5 U-DIMM and CU-DIMM memory kits. Users can easily achieve enhanced memory overclock performance by simply enabling the XMP profile in their motherboard's BIOS.

As a result of this certification, G.SKILL is now authorized to display the official Intel XMP Identifier Logo, ensuring that end users can confidently identify officially supported DDR5 memory kits validated for optimal overclocked memory specifications.
