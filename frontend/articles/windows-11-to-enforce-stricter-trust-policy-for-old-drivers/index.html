Windows 11、旧ドライバの信頼性ポリシーを厳格化へ

Windows 11 to Enforce Stricter Trust Policy for Old Drivers

リーク信頼度 Leak Credibility 65%

📋 要約

📋 Summary

  • MicrosoftはWindows 11のカーネルポリシーを更新し、期限切れ証明書を持つ旧ドライバをデフォルトで信頼しなくなる。
  • 2026年4月のWindowsアップデート以降、ドライバはWindows Hardware Compatibility Program (WHCP) 経由での署名が必須となる。
  • 後方互換性維持のため、既存の信頼された旧ドライバの読み込みは継続されるが、評価期間を経て新ポリシーが本格適用される。
  • Microsoft is updating its Windows 11 kernel policy to no longer default-trust old drivers with expired certificates.
  • From the April 2026 Windows update, drivers will require signing through the Windows Hardware Compatibility Program (WHCP).
  • Backward compatibility for existing trusted old drivers will be maintained, with full enforcement after an evaluation period.

Microsoftは、Windows 11のNTカーネルが旧式のドライバを信頼する既存のポリシーを刷新する方針を明らかにした。これまでのポリシーでは、2000年代初頭のクロスサイニングプログラムにより、証明書が期限切れとなった古いドライバも引き続き実行が許可されていたが、この運用が終了する。

2026年4月のWindowsアップデートより、Windows NTカーネルはWindows Hardware Compatibility Program (WHCP) 経由で署名された新しいドライバのみを受け入れるようになる。これにより、各ドライバはMicrosoftのセキュリティ基準を満たす有効なセキュリティ証明書を確実に取得する必要がある。

この変更はWindows 11 24H2、25H2、26H1、Windows Server 2025、および将来のリリースに適用される。Microsoftは後方互換性を維持するため、信頼された古いドライバの読み込みは引き続き許可するものの、新ポリシーは評価モードでの導入を経て、互換性問題がないことを確認した上で本格的に適用される見込みだ。

Microsoft has announced an update to its Windows 11 NT Kernel policy, which previously allowed old drivers with expired certificates to run. The long-standing cross-signing program from the early 2000s, which enabled such drivers to execute, will cease to function.

Starting with the April 2026 Windows update, the NT Kernel will exclusively accept new drivers signed through the Windows Hardware Compatibility Program (WHCP). This ensures that each driver possesses a valid security certificate meeting Microsoft's stringent security standards.

This policy change will impact Windows 11 24H2, 25H2, 26H1, Windows Server 2025, and future releases. While Microsoft intends to maintain backward compatibility for older, trusted drivers, the new policy will first be implemented in an evaluation mode to monitor driver activity before full activation to prevent compatibility issues.
