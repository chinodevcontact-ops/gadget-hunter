OpenAI CodexがMacでコンピューター操作、画像生成、記憶機能を追加

OpenAI Codex Adds Computer Use, Image Generation, and Memory on Mac

📋 要約

📋 Summary

  • OpenAI CodexがMacアプリの操作（カーソル操作、クリック、入力）が可能になった。
  • Codexはgpt-image-1.5を利用して画像生成機能を強化し、製品コンセプトやモックアップの作成に役立つ。
  • Codexはユーザーのワークフローに関する情報を記憶し、自動化機能を改善した。
  • OpenAI Codex is now able to operate desktop Mac apps with its own cursor, seeing what's on the screen, clicking, and typing to complete tasks.
  • Codex has been updated to use gpt-image-1.5 for generating images in the app.
  • Codex can now remember preferences, recurring workflows, tech stacks, and other information about each user's personal workflow.

OpenAIは、AIコーディングエージェントであるCodexのアップデートを発表した。今回のアップデートにより、CodexはMacアプリをカーソル操作で操作し、画面の情報を確認したり、クリックや入力を通じてタスクを完了したりすることが可能になったと報告されている。

CodexはMac上で複数のエージェントを並行して実行でき、ユーザーの作業を妨げることなく動作する。OpenAIによれば、開発者はアプリのテストやフロントエンドの変更などに役立つと見込まれている。また、Codexはユーザーのワークフローに関する情報を記憶し、以前の会話スレッドを利用して作業を再開したり、将来の作業をスケジュールしたり、数日または数週間かけてタスクに取り組んだりすることが可能になった。さらに、プロジェクトのコンテキスト、記憶、接続されたプラグインに基づいて作業を提案する。

Codexには、エージェントへのより正確な指示を与えるために、ページに直接コメントできるインアプリブラウザが搭載されている。将来的には、Codexはブラウザをフル活用し、ウェブサイトを開いたり、ユーザーフローを操作したり、スクリーンショットを撮ったり、出力を検査したりできるようになる予定である。

Codexは、製品コンセプトやモックアップの作成に役立つ画像生成のために、gpt-image-1.5を使用するようにアップデートされた。また、複数のターミナルタブのサポート、GitHubレビューコメントへの対応、PDFやスプレッドシートなどのドキュメントのプレビュー表示機能が追加された。さらに、Codexのコンテキスト収集とアクションを改善するために、90以上の新しいプラグインが追加された。

今回のアップデートは、ChatGPTにサインインしたCodexデスクトップユーザーに本日より順次配信される。パーソナライズ機能は、現時点ではEnterprise、Education、EU、UKのユーザーには提供されていないが、近日中に配信される予定である。コンピューター操作機能も、EUおよびUKではまだ利用できない。

OpenAI is making several updates to its Codex AI coding agent. Codex is now able to operate desktop Mac apps with its own cursor, seeing what's on the screen, clicking, and typing to complete tasks.

Codex can run multiple agents on the Mac in parallel, without interfering with the user's own work. OpenAI says developers will find it useful for testing apps, iterating on frontend changes, and more. Codex can now remember preferences, recurring workflows, tech stacks, and other information about each user's personal workflow. With automation improvements, Codex is able to resume work after a pause using existing conversation threads, and it can schedule future work for itself and work on a task across days or weeks. Codex also proposes work using context from projects, memory, and connected plugins.

There is an in-app browser for Codex that allows users to comment directly on pages to provide more precise instructions to the agent. In the future, Codex will get full use of the browser for opening websites, working through user flows, taking screenshots, and inspecting outputs.

Codex has been updated to use gpt-image-1.5 for generating images in the app, which OpenAI says is helpful for creating visuals for product concepts and mockups. Codex now includes support for multiple terminal tabs, addressing GitHub review comments, and opening files directly in the sidebar with rich previews for documents like PDFs and spreadsheets. Along with these changes, Codex has over 90 new plugins that can combine skills, app integrations, and MCP servers to improve Codex's context gathering and actions.

The updates to Codex are rolling out today to Codex desktop users signed in with ChatGPT. The personalization features are not yet available to Enterprise, Education, EU, and UK users, but will be rolling out soon. Computer use is also not yet available in the EU or the UK.
