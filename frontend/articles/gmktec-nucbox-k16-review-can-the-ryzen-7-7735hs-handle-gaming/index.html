  • Fast processing with LPDDR5X memory and PCIe 4.0 storage
  • Premium build quality with CNC-machined aluminum chassis, price around $650 (depending on exchange rate)

GMKtecからNucBox K16が登場しましたね。Ryzen 7 7735HSを搭載した小型PCで、OCuLinkという拡張インターフェースが目を引きます。これがあれば、外付けGPUを接続してゲーム性能を底上げできる...かも？

Zen 3+アーキテクチャの8コア16スレッド、最大4.75GHzとのことですが、僕の7800X3Dとはワッパ（電力効率）が違うので、単純比較はできないですね。内蔵GPUのRadeon 680Mは、軽いゲームなら動くレベルでしょうか。ARK: Survival Ascended (ASA)を快適にプレイしたい僕としては、OCuLinkでRX 9070 XTを繋げたいところです（笑）。

正直、小型PCに高性能GPUを繋げるのは、電源容量や冷却の問題で難しいことが多いです。GMKtecがちゃんと対策してくれているのか、様子見安定ですね。価格は158円/ドルのレートで計算すると、約10万円前後。バイト代で買える範囲なので、ちょっと気になる...

中の人の本音 (JP)

OCuLink拡張は面白い試みですね。ただ、小型PCで爆熱GPUを動かすのは、電源容量がネックになりそう。僕の9070 XTはTDP 355Wなので、それなりの電源が必要になりますからね。もしこれが本当なら、ですが、OCuLink対応の小型電源ユニットが充実してくるかもしれません。AMDのRyzen 7 7735HSは、普段使いには十分だと思いますが、AAAタイトルをガッツリ遊びたいなら、やっぱりデスクトップPCの方が安定ですね。個人的には、AMDしか勝たん（コスパ的に）。

GMKtec has launched the NucBox K16. This ultra-compact PC is powered by the Ryzen 7 7735HS and features an OCuLink expansion interface, which is pretty interesting. This allows you to connect an external GPU to potentially boost gaming performance.

The processor has 8 cores and 16 threads based on the Zen 3+ architecture, boosting up to 4.75GHz. However, comparing it to my 7800X3D isn't straightforward due to differences in power efficiency. The integrated Radeon 680M graphics should be able to handle light gaming. As someone who wants to play ARK: Survival Ascended (ASA) smoothly, I'd like to connect my RX 9070 XT via OCuLink (lol).

Honestly, connecting a high-performance GPU to a small PC often faces power supply and cooling issues. We need to see if GMKtec has addressed these concerns. At a rate of 158 yen/dollar, the price is around $650. That's within my part-time job earnings, so I'm a little interested...

Review (EN)

OCuLink expansion is a neat idea! But running a hot GPU in a small PC will likely be a power supply bottleneck. My 9070 XT is 355W TDP, so you need a decent PSU. If this takes off, we might see more compact PSUs with OCuLink support. Ryzen 7 7735HS is fine for daily use, but for AAA gaming, a desktop PC is still more stable. AMD all the way (for value)! 🚀
