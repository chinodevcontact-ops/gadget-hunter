📋 Summary

  • Bungieの新作FPS『Marathon』は、オープンプレビュー「Server Slam」を経て、2026年3月5日に正式リリース予定。
  • Steamでは既に約25万本の売上が推定されており、発売前から高い関心が寄せられている。
  • Server Slamでのプレイヤーフィードバックは既に一部修正され、残る問題は発売後も継続して調整される見込み。
  • Bungie's new FPS 'Marathon' is set to officially launch on March 5, 2026, following its open preview 'Server Slam'.
  • Estimated sales on Steam have already reached approximately 250,000 copies, indicating significant pre-launch interest.
  • Player feedback from the Server Slam has led to some immediate fixes, with remaining issues to be addressed post-launch.

Bungieが手掛ける新作一人称視点抽出シューター『Marathon』が、オープンプレビュー「Server Slam」を終え、2026年3月5日にPS5およびPC向けに正式リリースされる予定だ。

このプレビュー期間中、プレイヤーはゲームを無料で体験し、多数のフィードバックを開発元に提供した。Bungieは既に一部の問題に対応し、Server Slam中に修正を適用したと報告されている。その他の課題についても、発売後も引き続き調査・調整を進める見込みである。

また、データによるとSteamでは発売を前に既に約25万本の販売が推定されており、Extraction Shooterというジャンルへの期待の高さが伺える。
