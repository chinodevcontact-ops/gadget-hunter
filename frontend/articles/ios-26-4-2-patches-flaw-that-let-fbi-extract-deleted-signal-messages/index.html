iOS 26.4.2でFBIが削除済Signalメッセージにアクセスする脆弱性を修正

iOS 26.4.2 Patches Flaw That Let FBI Extract Deleted Signal Messages

リーク信頼度 Leak Credibility 65%

📋 要約

📋 Summary

  • Appleは、FBIが削除されたSignalメッセージのプレビューにアクセスできるセキュリティ脆弱性を修正した。
  • この脆弱性は、削除されるはずの通知がiPhoneまたはiPadに保持されるというもの。
  • iOS 26、iPadOS 26、iOS 18、iPadOS 18を使用しているユーザーは、最新バージョンにアップデートすることが推奨される。
  • Apple has patched a security vulnerability that allowed the FBI to access previews of deleted Signal messages.
  • The flaw allowed notifications that were supposed to be deleted to be retained on an iPhone or iPad.
  • Users running iOS 26, iPadOS 26, iOS 18, or iPadOS 18 are advised to update to the latest versions.

Appleは本日、iOS 26.4.2、iPadOS 26.4.2、iOS 18.7.8、およびiPadOS 18.7.8のアップデートをリリースし、FBIが最近利用していたセキュリティ脆弱性を修正したことが明らかになった。この脆弱性により、アプリが削除された後でも、iPhoneからSignalメッセージのプレビューを抽出することが可能となっていた。

通知サービスに関する欠陥により、削除されるはずだった通知がiPhoneまたはiPadに保持される問題が発生していた。Appleは、データリダクションの改善により、このロギング問題を修正したと報告している。

Appleはこの脆弱性の存在を、最近の法廷証言でFBIが特定の事件に関連するiPhoneの内部通知データベースにアクセスし、法執行機関にメッセージプレビューへのアクセスを提供していたことを受け、認識した。問題のiPhoneは、Signalメッセージの内容をロック画面に表示するように設定されており、その機能が有効になっていると、iPhoneはメッセージの内容を保存する。

事件の被告はSignalアプリを削除し、Signalメッセージが消えるように設定していたが、iPhoneはそのメッセージをデータベースに保持し、FBIがアクセスするのに十分な時間があった。

iOS 26、iPadOS 26、iOS 18、またはiPadOS 18を使用しているAppleユーザーは、このセキュリティ欠陥の影響を受けないように、最新バージョンにアップデートすることが推奨される。

Apple today released the iOS 26.4.2, iPadOS 26.4.2, iOS 18.7.8, and iPadOS 18.7.8 updates that address a security vulnerability that the FBI recently used to extract Signal message previews from an iPhone even after the app was deleted.

A flaw with notification services allowed notifications that were supposed to be deleted to be retained on an iPhone or iPad. Apple says it fixed the logging issue with improved data redaction.

Apple became aware of the vulnerability after recent court testimony revealed that the FBI was able to access the internal notification database on an iPhone involved in a case, providing law enforcement with access to message previews. The iPhone in question was set to display the content of Signal messages on the Lock Screen, and with that feature enabled, the iPhone stores message content.

The defendant in the case had deleted the Signal app and had Signal messages set to disappear, but the iPhone kept the messages in its database long enough for the FBI to access them.

Apple users running iOS 26, iPadOS 26, iOS 18, or iPadOS 18 should update to the latest versions to avoid being impacted by the security flaw.
