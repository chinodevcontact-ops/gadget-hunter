Microsoft Halts Auto-Install of 365 Copilot App on Windows 11 Amid Backlash

📋 Summary

  • Microsoft 365 CopilotアプリのWindows 11への自動インストール計画が一時停止された。
  • 「AI everywhere」戦略へのユーザーからの強い反発が停止の主な理由。
  • 今後はOSのバグ修正とコア機能の強化に注力すると発表。
  • Automatic installation of Microsoft 365 Copilot app on Windows 11 has been temporarily disabled.
  • Decision follows significant user backlash against the company's 'AI everywhere' strategy.
  • Microsoft states a new focus on fixing bugs and enhancing core OS features.

Microsoftは、Windows 11における「Microsoft 365 Copilot App」の自動インストール計画を一時的に停止したと報じられています。この措置は、AI統合へのユーザーからの強い反発、特に同社の「Copilot everywhere」戦略に対する批判を受けたものです。

元々2025年12月に予定されていたこの自動インストールは、Microsoft 365デスクトップアプリが導入されているWindowsデバイスを対象としていました。しかし、ユーザーコミュニティからは、特にAI機能の価値に疑問を呈する声や、強制的な導入への抵抗が顕著でした。

Microsoftは現在、バグの多いOSの修正や、Windows 11のコア機能強化を通じたユーザーエクスペリエンスの向上に焦点を当てており、「AI-everywhere」のアプローチから一歩引く姿勢を示しています。既存のインストールには影響がなく、管理者は引き続き他の方法でアプリを展開できます。

Microsoft has reportedly decided to temporarily disable the automatic installation of its Microsoft 365 Copilot App on Windows 11. This decision comes after significant user backlash against the company's aggressive 'AI everywhere' integration strategy into the operating system.

The automatic deployment, initially slated for December 2025 for Windows devices with Microsoft 365 desktop apps, faced strong criticism from the community, particularly from enthusiasts who saw little added value in the forced AI integrations.

Microsoft is now signaling a step back from its 'AI-everywhere' approach, stating a renewed focus on addressing core OS bugs and enhancing fundamental features for a smoother Windows 11 user experience. Existing installations remain unaffected, and administrators retain options for manual deployment.
