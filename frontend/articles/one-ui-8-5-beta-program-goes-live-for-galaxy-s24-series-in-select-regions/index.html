Galaxy S24シリーズ向け「One UI 8.5 Betaプログラム」が韓国・インド・英国で開始

One UI 8.5 Beta Program Goes Live for Galaxy S24 Series in Select Regions

📋 要約

📋 Summary

  • Samsung Galaxy S24シリーズ向けOne UI 8.5のベータプログラムが開始された。
  • 対象地域は韓国、インド、英国の3カ国。
  • 具体的なビルドバージョンとして「S928BXXU5ZZCD」などが確認されている。
  • One UI 8.5 Beta Program launched for Samsung Galaxy S24 series.
  • Available in Korea, India, and the UK.
  • Build version "S928BXXU5ZZCD" and others confirmed.

Samsungは、フラッグシップスマートフォンGalaxy S24シリーズ向けに次期Android OSスキンとなる「One UI 8.5」のベータプログラムを、韓国、インド、英国で開始したことが明らかになりました。

このベータプログラムは、一般ユーザーが正式リリース前のソフトウェアを先行体験し、フィードバックをSamsungに提供することで、バグの修正や機能改善に貢献することを目的としています。確認されているビルドバージョンには「S928BXXU5ZZCD」などが含まれており、地域やモデルによって異なる可能性があります。

One UIのメジャーアップデートでは、通常、ユーザーインターフェースの刷新、新機能の追加、既存機能のパフォーマンス改善などが盛り込まれます。今回のOne UI 8.5においても、Galaxy AI機能のさらなる拡張や安定性向上に焦点が当てられているものと見られます。

Samsung has officially launched the One UI 8.5 Beta Program for its flagship Galaxy S24 series in select regions, including Korea, India, and the United Kingdom.

This beta initiative allows early adopters to test pre-release software and provide valuable feedback to Samsung, contributing to bug fixes and feature refinements. Confirmed build versions include "S928BXXU5ZZCD," with variations expected across regions and specific S24 models.

Major One UI updates typically introduce user interface enhancements, new features, and performance improvements. For One UI 8.5, further expansion and stabilization of Galaxy AI functionalities are anticipated.
