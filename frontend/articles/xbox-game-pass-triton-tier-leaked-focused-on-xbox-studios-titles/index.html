Xbox Game Pass 'Triton' Tier Leaked, Focused on Xbox Studios Titles

📋 Summary

  • Xbox Game Passの新規サブスクリプションティア「Triton」の存在がコード解析により判明
  • 新ティアはXbox Game Studiosのファーストパーティタイトルのみを提供予定
  • 広告付き無料、または低価格での提供が推測されており、Netflixとのバンドルも示唆
  • New Xbox Game Pass tier 'Triton' revealed through code analysis leak
  • The new tier is expected to exclusively offer first-party Xbox Game Studios titles
  • Speculated to be ad-supported free or low-cost, with potential Netflix bundle partnership

Xboxの新しいCEO、アシャ・シャルマ氏が計画するGame Passの新サブスクリプションティアに関する情報が、Xbox Cloud Gamingの機能を拡張するオープンソースサービス「Better xCloud」によるコード解析で明らかになった。

Better xCloudの公式Xアカウントの投稿によると、Game Passのアップデートコード内に「Triton」というコードネームの新ティアが存在し、通常のGame Passがサードパーティ製タイトルも含むのに対し、この新ティアはXbox Game Studios製のファーストパーティタイトルのみで構成されるという。正確な価格は不明ながら、広告付きの無料または低価格での提供が推測されており、Microsoftがライセンス費用を削減し、過去数年間のスタジオ買収を最大限に活用する戦略と見られている。また、XboxとNetflixとのバンドルサブスクリプション提携の布石である可能性も指摘されている。

Information regarding a new Xbox Game Pass subscription tier, planned by Xbox's new CEO Asha Sharma, has surfaced through code analysis by Better xCloud, an open-source service enhancing Xbox Cloud Gaming functionality.

According to Better xCloud's official X account, the Game Pass update code contains a new tier codenamed 'Triton.' Unlike the standard Game Pass, which includes third-party titles, this new tier will exclusively feature first-party games from Xbox Game Studios. While exact pricing remains unknown, speculation suggests an ad-supported free or low-cost model. This strategy is believed to enable Microsoft to reduce licensing costs and leverage its numerous studio acquisitions. The leak also hints at this potentially laying the groundwork for a bundled subscription partnership between Xbox and Netflix.
