📋 Summary

  • PowerToys 0.99で、Altキーを押しながら左クリックでウィンドウを移動、右クリックでリサイズする機能「Grab and Move」が追加された。
  • 外部ディスプレイの設定（ソース、電源状態、明るさ、コントラスト）をタスクバーから変更できる「Power Display」が追加された。

  • PowerToys 0.99 adds 'Grab and Move' feature, allowing window movement with Alt + left click and resizing with Alt + right click.
  • A 'Power Display' feature is added to change external display settings from a taskbar fly-out menu.
  • Improvements to the keyboard layout editor, a compact dock option for Command Palette, and persistent calculator history are included.

Microsoft PowerToysのアップデート0.99がリリースされたことが明らかになった。今回のアップデートでは、Linuxのデスクトップ環境に似た機能が追加されている。特に注目すべきは「Grab and Move」機能で、Altキーを押しながら左クリックすることでウィンドウを、右クリックでウィンドウのリサイズを、ボーダーを狙うことなく行うことができる。この機能は、KDE PlasmaやGnomeなどのLinuxデスクトップ環境で一般的な操作方法と類似している。ただし、Linuxでは通常SystemキーまたはWindowsキーが修飾キーとして使用される。

また、「Power Display」機能も追加され、タスクバーのフライアウトメニューから外部ディスプレイのソース、電源状態、明るさ、コントラストなどの設定を変更できるようになる。さらに、ディスプレイプロファイルを作成し、タスクバーメニューから選択することも可能だ。キーボードレイアウトエディタも改善され、物理的に存在しないキーを選択してショートカットやコードを設定できるようになった。Command Paletteにはコンパクトドックオプションが追加され、電卓履歴の保持や、ドックへのアプリのピン留め方法、ドックとウィンドウの相互作用に関するオプションが追加されている。

The release of Microsoft PowerToys update 0.99 has been announced. This update adds features similar to those found in Linux desktop environments. Notably, the 'Grab and Move' feature allows users to move windows by holding Alt and left-clicking, and resize them with Alt and right-clicking, without needing to aim for the border. This functionality is similar to common operations in Linux desktop environments such as KDE Plasma and Gnome. However, Linux typically uses the System or Windows key as a modifier.

Additionally, a 'Power Display' feature has been added, allowing users to change settings such as the source, power state, brightness, and contrast of external displays from a taskbar fly-out menu. Users can also create display profiles and select them from the taskbar menu. The keyboard layout editor has also been improved, allowing users to select keys that are not physically available on their keyboard when setting up shortcuts and chords. Command Palette has added a compact dock option, along with persistent calculator history and options for how applets pin to the dock and how the dock interacts with windows.
