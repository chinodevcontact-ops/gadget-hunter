Canonicalは、次期LTS（長期サポート）リリースとなる「Ubuntu 26.04 LTS “Resolute Raccoon”」において、推奨システムメモリ要件を6GBに引き上げたことを発表した。これは2018年のUbuntu 18.04 LTSで4GBに設定されて以来、初の大きな変更となる。

この変更は、コアOS自体の肥大化によるものではなく、更新されたGNOMEデスクトップ環境やFirefoxなどの最新Webブラウザ、LibreOfficeといった日常的なアプリケーションが、マルチタスキングシナリオにおいてより多くのメモリを要求するようになった現状を反映していると説明されている。ストレージ要件（25GB）とCPU要件（2GHzデュアルコア）は据え置きだ。

なお、6GBはあくまで「推奨」であり、それ以下のメモリを搭載したシステムでもインストールは可能だが、パフォーマンスが低下する可能性がある。低スペックなハードウェアを利用するユーザー向けには、公式フレーバーのLubuntuやLinux Liteといった軽量版ディストリビューションが引き続き提供される。

Canonical has announced an increase in the recommended system memory for the upcoming Ubuntu 26.04 LTS "Resolute Raccoon" to 6 GB, marking the first significant change since 2018's 4 GB recommendation for Ubuntu 18.04 LTS.

This adjustment is attributed not to a heavier core OS, but to the increased demands of modern workloads, including updated GNOME desktop environments, current web browsers like Firefox, and everyday applications such as LibreOffice, especially in multitasking scenarios. Storage (25 GB) and CPU (2 GHz dual-core) requirements remain unchanged.

While 6 GB is a recommendation, not a hard requirement, installation on systems with less memory is possible, though performance may suffer. For users with lower-end hardware, lighter official flavors like Lubuntu and distros such as Linux Lite remain viable options.
